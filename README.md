# Eco

## Описание

Клеточная экосистемная симуляция на `pygame` с картой мира, типами ландшафта, травоядными и хищниками. Проект сочетает генерацию мира, базовое поведение существ и терминал событий в одном окне.

## Возможности

- генерация мира с несколькими биомами;
- отдельные типы существ с разным поведением;
- пошаговое обновление популяции;
- лог событий и простое информационное меню;
- визуализация экосистемы на сетке.

## Стек

- Python
- pygame

## Запуск

```bash
pip install pygame
python game.py
```
